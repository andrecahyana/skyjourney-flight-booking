# SkyJourney — Flight Booking (Starter)

This repository contains a starter React + Vite project for the SkyJourney flight booking UI.

What I created for you in this commit:

- Vite + React project scaffolding
- Tailwind CSS configured (postcss + tailwind)
- Basic folder structure: src/, components/, pages/, layouts/, routes/, store/, services/, utils/
- Minimal Redux slices (auth, flights, booking)
- Example Home page and common components (Button, Input, Loader)
- API helper (axios)
- sample data (src/data/dummyFlights.json)

Quick start

1. Clone

   git clone https://github.com/andrecahyana/skyjourney-flight-booking.git
   cd skyjourney-flight-booking

2. Install

   npm install

3. Run (development)

   npm run dev

Notes

- Add your API URL to `.env` as `VITE_API_URL` if you want to connect a real backend.
- I can continue by implementing SearchResult, FlightDetail, Booking flow, authentication pages, and CI/CD (Vercel) deployment.
